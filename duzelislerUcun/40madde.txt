1. Garage membership validation gücləndirilsin

    Fayl: app/Http/Middleware/EnsureGarageSelected.php

    İzah: Session-dakı garage_id-nin həmin istifadəçiyə məxsus olduğu yoxlanılsın. Yalnız session-a güvənmə.

    Kod:

php

$garageId = session('current_garage_id');
if (!$garageId || !auth()->user()->garages()->where('garage_id', $garageId)->wherePivot('is_active', true)->exists()) {
    session()->forget('current_garage_id');
    return redirect()->route('garage.selection');
}
